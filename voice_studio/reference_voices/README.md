# Reference Voices Directory (`voice_studio/reference_voices`)

Drop your clean 10-second reference voice sample here (git-ignored for privacy and repo hygiene):

1. `pierre_ref.wav` — Clean 10–15s recording (WAV preferred, 16-bit or 24-bit mono/stereo) with minimal background noise.
2. `pierre_ref.txt` — Exact verbatim UTF-8 transcript of the spoken words in `pierre_ref.wav`.

Alternatively, record or upload directly inside **Tab 1** of the Gradio Voice Studio UI (`http://127.0.0.1:7860`).
